`prospoolcare.com` uses Vercel project `crpools/rivera-pool-care` and GitHub repository `Claudio-1973/rivera-pool-care`. `riverapoolsriverside.com` uses Vercel project `crpools/mockup-sandbox` and the monorepo repository `Claudio-1973/Riverapools`.

**Why:** Both projects share Rivera branding and live in the same Replit workspace, but their Vercel deployments and GitHub repositories are separate.

**How to apply:** Before syncing or publishing, match the domain to this mapping; do not update `Riverapools` for `prospoolcare.com`.
